明明是三月日记，结果一直拖延直到四月中旬才写，实在有点偷懒了。上次写日记还穿着羽绒服，现在已经在穿短袖了🤭

三月已经过去这么久我也记不太清发生什么了，干脆就当一个阶段性总结好了

# 依旧很没效率地学习中

从上次写日记到现在，总算是把 Redis 这一块过了一遍，本来计划着寒假就搞完的东西，结果现实中发生了这么多事，一下子全乱了套了。

把黑马的Redis视频从头到尾结结实实过了一遍，点评也跟着敲了绝大部分，但即使是这样依然觉得有点懵懵懂懂的，看的时候貌似会了，关上视频自己思考的时候总觉得不对，要不就是哪个环节忘了要不就是记错了。只能说分布式和并发这块的东西还是接触太少了，工程上的东西绝不是简简单单看一遍视频就能完全吃透的。后面有时间再结合八股好好复盘一下项目吧。

除了 Redis，还速通了一下 RabbitMQ 和 ElasticSearch ，刷视频还是蛮快的，就是因为是速通，完全没有上手敲代码，和点评一样，后面再说吧。而且只看一个 RabbitMQ 感觉还是不太够，下周再补一补 Kafka 的知识，以及速通一下微服务相关内容会比较好。

除了传统后端，最近 agent 也特别的火，招聘软件上好多后端岗都变成agent岗了， 没办法只好跟着再速通一下。前两天把 hello-agents 速通了一下，前面讲的都不错，尤其 memory 那块确实很有启发，只不过后面那个旅行助手的项目太玩具了，感觉像是一本好书到结局拉了个大的，前面讲了那么多的 memory，rag，还有一些 agent 架构，项目通通没用上🤷‍♂️下周开始考虑看一下 nanobot，顺便再把 LangChain 和 LangGraph 速通一下，有精力的话看看 LangChain4j 吧。

然后就是 LeetCode，从1月多到现在一道题没刷，属于是之前的武功又损失地差不多了，今天才开始重新拾起来。不过好消息是，一些easy 和 medium 还有大致思路，一两次 debug 就能过；坏消息是之前觉得没思路的某些题现在再看依旧没思路。打算从今天开始每天5道，先刷完整一遍 hot100 再说。

至于科研。。基本算是停滞状态吧，不过我本身也没有什么学术追求，能按时毕业就行。

# 玩玩游戏

3月最兴奋的事情就是——终于换了台电脑！吭哧吭哧干了5年的 ThinkPad 终于可以休息了，我也终于用上了人生中第一台带独显的电脑。不得不说新机器就是好啊，反应速度也快，内存也大（虽然才16G，但是比原来的8G好多了），还带一个5060。这下终于实现游戏自由了，之前想玩玩不了的终于可以放开了打😎

话虽如此，我现在好像也没那么想打游戏了。看着 steam 里的收藏，最后一个也没下单。最后在电脑上下了个鸣潮，每天十来分钟清个任务就下，switch也好久没有打开了。最近唯一玩的比较多的就是杀戮尖塔2了吧，主要是同学买了一个感觉还不错，想和我联机玩。游戏果然还是多人玩有意思，一个人的时候什么都不想打开。

啊，除了游戏最近倒是玩了很多claude code，这东西对我来说太新鲜功能太强大了，有点后悔怎么现在才开始用。github 上好多有意思的 skills，前几天我还整了一个蒸馏自己，效果还挺不错hhhh，就是从微信导出聊天记录的那几个仓库被腾子发函下架了，不然效果肯定更好。等我后面几天再学学agent，直接让他帮我 vibe 一个demo感觉也挺好玩。不过有一个缺点就是我用的 MiniMax，便宜是便宜就是效果不怎么好，模型傻傻的，高峰时段还容易阻塞，只能分时段用，后面真要高强度用可以考虑给 Qwen 氪金了😵‍💫

# 其他乱七八糟的

从爷爷去世到现在已经六七十天了，不过我基本上每隔一两天睡醒的时候都会想起他，总是无意识地在想快放假的那天晚上我去看他的场景，虚弱的他怎么就那天突然跟我说起他之前的事情了呢。前几次看他我们的话题总是围绕着他的身体他的病情，怎么就那天他主动把话题引到一个平时不怎么说的方向上，还说了不少（当然是和他平时说不了几句话相比，算不少了）。那天要是我没听他的话回家，直接在那边住一晚上多陪陪他就好了。唉，不光早上起床的时候脑子会无意识地想，晚上躺床上睡前有时也会想起来，一想起来就有一种酸酸的感觉，也不知道到底算不算悲伤，像是被情绪的巨浪掀了个底朝天，复杂到说不上来的感觉。

清明回家老妈还说感觉我上了研究生比本科的时候更恋家了，说得我还怪不好意思的。其实倒也没有恋家吧，无论是之前还是现在，我一个人过的时候也挺好的，绝大部分时间也挺自在。可能真得一个重大的打击才能让我更清楚地意识到我追求的东西吧，其实我上学期和本科时期没什么两样，觉得家太远就懒得回，过节最多打个电话就好了，直到爷爷去世我才不得不直面生死这个话题。满打满算我将来能见到爸妈能和他们一起生活的日子也不多了，我只是想尽可能地多陪陪他们而已，说白了我追求的从来没有什么高大上的自我价值或是财富权力，我只是想一辈子都和我爱的人在一起罢了。之前我总是在想我要赚多多的钱，这样等家人们病了就有钱给他们治病，但是现在想来有点舍本逐末了，如果只是为了赚钱而牺牲了我和家人的相处，那又有什么用呢，无非是再添一份后悔。

想了很久，我现在对未来的工作越来越迷茫了，我希望能陪在他们身边，但又怕为了这个目的选一个薪资不是很高的工作，将来家里真出什么事了又没钱处理，要是因为没钱导致治不好病或他们受苦那又怎么办呢，我估计该后悔一辈子了。说到底一份平衡的工作太难找了，想太多也没有用，只好走一步看一步吧，但愿最后结果不会太坏。

不知不觉已经能看到夏天的影子了，窝在宿舍沉重地思考不如想想怎么一步步提升，努力达到心目中理想的自己。一会去冲个澡，凉快凉快后给爸妈打个电话，休息一阵后就要接着努力了。等明天的太阳升起来，那就是新的一天🌞
